    How each pane is rendered
    
    
    The first pane plays the source as it arrived: a Spine rig with its
      own atlas, a SkelForm archive, or a Godot scene packed for the browser engine. Every
      pane after it plays what a conversion wrote — the Spine runtime, the
      real engine, or SkelForm's own web player on the written .skf — so one
      upload shows the rig in every tool at once. A format the rig is already in is not
      converted into itself, and when a pane cannot be built (a Godot target with no engine
      binary to export with) that side replays through the Spine leg and its folder says
      via-spine.
